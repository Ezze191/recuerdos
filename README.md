# Nuestra Historia de Amor

Una landing page interactiva y romántica para celebrar nuestra relación, diseñada con mucho cariño.

## Tecnologías
- **React**: Biblioteca principal.
- **Tailwind CSS**: Estilos modernos y rápidos.
- **Framer Motion**: Animaciones fluidas y elegantes.
- **Lucide React**: Iconos bonitos.

## Cómo ver la página
1. Asegúrate de estar en la carpeta del proyecto.
2. Instala las dependencias (si es necesario):
   ```bash
   npm install
   ```
3. Inicia el servidor local:
   ```bash
   npm run dev
   ```
4. Abre tu navegador en la dirección que te mostrará la terminal (ej. `http://localhost:5173`).

## Personalización
Puedes editar los archivos en la carpeta `src/components` para cambiar los textos, fechas y fotos.
- **Timeline.jsx**: Agrega tus propias fechas importantes.
- **Gallery.jsx**: Cambia las imágenes por las tuyas (puedes subir fotos a una carpeta `public/images` o usar URLs externas).
- **LoveLetters.jsx**: Escribe tus propios mensajes de amor.
